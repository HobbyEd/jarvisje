Sogyo Kennis Chatbot
Platform Overzicht

Domein-specifieke RAG-chatbot. Productie op 192.168.165.15 met lokaal Ollama gemma3:4b, publiek via https://jarvisje.com (Cloudflare Tunnel).

Globaal overzicht

Eén host: app, embeddings, vector store en LLM. Geen externe cloud-LLM voor de kern.

Ingestie
Sitemap-first scraper, BGE-M3 embeddings (CPU), Chroma. 6 bronnen. Indexering met token.
Chat
Retrieval → orchestrator → Ollama (OpenAI-compatible) → SSE streaming + citations.
Ops
Docker Compose + systemd + cloudflared. Data in persistent volume.

Architectuur

flowchart LR Browser[Browser jarvisje.com] CF[cloudflared] App[sogyo-chatbot-app :8080] Chroma[(Chroma volume)] Emb[BGE-M3 CPU] Ollama[Ollama gemma3:4b GPU] Browser --> CF --> App App --> Emb --> Chroma App --> Ollama

Platform starten (lokaal dev)

1

LLM (Ollama)

Productie: Ollama op .15 poort 11434, model gemma3:4b.

export LLM_BASE_URL=http://192.168.165.15:11434/v1
export LLM_MODEL=gemma3:4b
export EMBEDDING_DEVICE=cpu
2

Python API

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scripts/run_api.py
# → http://localhost:8001
3

Indexering

Via UI (tab Bronnen, indexeringstoken) of CLI:

python scripts/ingest.py --max 500
# of via UI: max artikelen 500, sitemap-first crawl

  • Build bij voorkeur op de server (amd64), zonder sudo als user in docker-group
  • Runbooks: deployment.md, ubuntu-x64 README
  • Publiek: Cloudflare Tunnel → http://127.0.0.1:8080
